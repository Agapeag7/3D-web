# Projet 3D-CSS

Ce projet est une démonstration d'effets 3D et de mise en page CSS. Il contient des styles et des éléments visuels pour créer une interface interactive en trois dimensions.

## Contenu

- Mise en page responsive
- Animations CSS 3D
- Cartes et éléments transformés en perspective
- Structure simple pour ajouter du contenu

## Installation

1. Ouvrez le dossier du projet dans votre éditeur.
2. Assurez-vous que les fichiers HTML, CSS
3. Ouvrez le fichier HTML dans votre navigateur pour voir le rendu.

## Images

Ajoutez au moins 10 images dans le dossier `img`.
Ces images seront utilisées dans le projet pour les éléments visuels et les arrière-plans.

Mettez le nom des images dans le code du slider ci-dessous :

```html

    <div class="item" style="--position: 1"><img src="img/n1.jpg" alt=""></div>
```
